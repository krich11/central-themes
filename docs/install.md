# Install

This is the end-user download page. Zips live on **[GitHub Releases](https://github.com/krich11/central-themes/releases)** — not in the git tree.

**[Latest release](https://github.com/krich11/central-themes/releases/latest)** — download the Chrome/Edge `.zip` asset. Ignore “Source code (zip)” and “Source code (tar.gz)”.

## Load in Edge or Chrome

The extension is not on the Chrome Web Store yet. Load it unpacked:

1. Open the [latest release](https://github.com/krich11/central-themes/releases/latest) and download the Chrome/Edge zip
2. Unzip it to a folder you will keep (Edge/Chrome need that folder to stay on disk)
3. Open `edge://extensions` or `chrome://extensions`
4. Turn on **Developer mode**
5. Click **Load unpacked**
6. Choose the unzipped folder that contains `manifest.json`
7. Open Aruba Central and **refresh that tab** so the theme can attach

To update later, download the newer zip from the latest release, unzip over the same folder (or load the new folder), then click **Reload** on the extension card and refresh Central.

Older builds: [all releases](https://github.com/krich11/central-themes/releases).

Do not commit zip files into this repo. Attach them to a GitHub Release when a version ships.
