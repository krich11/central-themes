# Install

This is the end-user download page. Zips live on **[GitHub Releases](https://github.com/krich11/central-themes/releases)** — not in the git tree.

## Current release

| Version | Browser | File |
| --- | --- | --- |
| **0.2.6** | Chrome / Edge | [central-themes-0.2.6-chrome.zip](https://github.com/krich11/central-themes/releases/download/v0.2.6/central-themes-0.2.6-chrome.zip) |

Download **the zip only**. Ignore “Source code (zip)” and “Source code (tar.gz)” on the release page.

## Load in Edge or Chrome

The extension is not on the Chrome Web Store yet. Load it unpacked:

1. Download the Chrome/Edge zip from the table above
2. Unzip it to a folder you will keep (Edge/Chrome need that folder to stay on disk)
3. Open `edge://extensions` or `chrome://extensions`
4. Turn on **Developer mode**
5. Click **Load unpacked**
6. Choose the unzipped folder that contains `manifest.json`
7. Open Aruba Central and **refresh that tab** so the theme can attach

To update later, download the newer zip, unzip over the same folder (or load the new folder), then click **Reload** on the extension card and refresh Central.
